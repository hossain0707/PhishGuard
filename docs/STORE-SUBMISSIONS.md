**Full description:**

PhishGuard is a student-developed browser extension for evaluating selected URL and page-structure risk indicators. It provides explainable, heuristic risk scores and warnings while you browse.

Features:

- Local assessments of HTTP/HTTPS webpage URLs and structural signals such as password fields, forms and embedded frames.
- LOW, MEDIUM and HIGH risk classifications with visible explanations. MEDIUM warnings provide a temporary page-specific proceed option; HIGH warnings do not.
- Optional account-free guest mode with local risk history.
- Optional Supabase account sign-in for account-separated local records and a browser registration feature.
- On-device dashboard and monthly PDF activity exports.

**Important limitations:** PhishGuard is an FYP prototype, not a substitute for established browser protections or independent security judgment. Checks happen after the page has started loading, and the rules may miss malicious sites or flag legitimate ones. A LOW score does not guarantee safety. Browser-internal pages cannot be assessed. It does not inspect page text or passwords.

## Permission justifications for Microsoft Edge

- **Single purpose:** Local browser-page heuristic risk assessment with explainable warnings, private history and reports.
- **`storage`:** Save risk history, account-separated settings and browser-session authentication state locally; supports local reporting and warning exceptions.
- **`tabs`:** Associate verified scanned URLs with active browser tabs, present the popup's current-tab result and navigate risky tabs to warning pages.
- **`http://*/*`, `https://*/*`:** Structural analysis applies to user-visited HTTP/HTTPS pages; narrower host permissions would prevent evaluating unfamiliar sites. Scans do not read credentials, page text or form submissions.
- **Remote code:** No remotely hosted executable code; dependency JS is bundled in the packaged extension. The extension calls Supabase for optional authentication and registration.
- **Data disclosure:** Optional account signup/login transfers an email, display name and authentication data to Supabase Auth. Optional browser registration transfers browser/extension metadata. URL assessments and local history are not uploaded to the backend. URLs have query/fragment/userinfo removed before local storage, though paths may still contain personal information. Document how the publisher will handle access/deletion requests before submitting.
