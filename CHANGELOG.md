# Changelog

## 4.1.0 — implementation candidate

- Unified source repository with browser-specific generated targets and a single Vercel website.
- Supabase SDK account flows, session refresh, password recovery and account-separated local history.
- Correct domain boundaries, IPv6 checks, dynamic reassessment, current-tab results and controlled warning exceptions.
- Paginated PDF download, month selection and Unicode-preserving print alternative.
- Database ownership policies, privacy controls and Firefox optional browser-registration consent.
- Professional architecture/setup/demo documentation, animated repository visuals and actual UI screenshots using labelled controlled fixtures.
- Formatting, automated CI, dependency monitoring and offline-logout regression coverage.

This version remains a release candidate until live Supabase configuration, email delivery, physical browser/mobile testing, representative detection evaluation and store approvals are verified.
